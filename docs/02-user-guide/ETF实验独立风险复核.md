# ETF 实验的独立风险复核

当 qutumn 已保存候选规则、开发期与后段收益和风险指标，RD-Agent 的 etf_tools.independent_review 可以通过标准输入把实验提交给本仓库的 cli/local_etf_research.py。请求使用 review_experiment 动作。该动作调用 ETF 防御情景分析师 safe_analyst_v2，返回 assessment、role 和 model。历史回测和候选生成分别由 qutumn 与 RD-Agent 的研究入口负责。

复核时应提供交易时点、是否扣费、开发与后段日期、各段触发数、与基线的收益差和回撤。对于看过数据后挑选的规则，应在输入中标明历史区间曾参与策略设计，便于区分回顾和前瞻证据。完成时保存实际返回的评估正文；空正文或模型以 length 结束会被运行器拒收。

2026-11-25，588170 高开减仓实验调用了此入口。配置模型 glm-5.3 在最后一次尝试达到 16,384 个输出 token 后仍被截断，未获得完整评估；账户模拟产生的收益不代表该角色认可了候选。另一个由 RD-Agent 发起的竞价因子实验在编码阶段由用户停止，尚未进入回测后的复核。
